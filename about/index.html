我是谁

我是 Verser_Vv，你也可以称呼我为小 V。

本科毕业于西北民族大学，硕士毕业于广东工业大学。

在大族激光做过嵌入式软件设计工程师，也在地平线（地瓜机器人）做过机器人应用工程师。现在在 Seeed Studio 继续做机器人相关的工作。

我在做什么

  • 边缘智能 / TinyML —— 把检测与识别模型塞进 MCU、ESP32 这类资源受限的设备。
  • 无人机视觉与自主拦截 —— 小目标检测、视觉跟踪与制导。毕业设计《小目标无人机检测与拦截控制研究》用 ROS 2 + PX4 把 YOLO11 与 LightTrack 的结果接到比例导引律上完成拦截；为此自建了 Drone-10k 数据集（10,000 张，Pascal VOC）。
  • 模型压缩与部署 —— Int8 定点量化、算子融合、TFLite / 裸机 C++ 推理。

经历

技能

  • 框架 / 平台：PyTorch（YOLO 系列）、ROS / ROS 2、OpenCV、PX4 Autopilot、TensorRT
  • 嵌入式 / 硬件：ESP32 / ESP8266、STM32、Jetson Nano、RK35XX、8051、RTOS
