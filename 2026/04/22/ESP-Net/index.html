ESP-Net：基于 ESP32 的轻量级嵌入式手写数字识别系统设计与实现

发表于 2026-04-22 更新于 2026-09-25 分类于 项目实战
在 ESP32（WT32-SC01）上完整落地的端侧手写数字识别系统。抛弃第三方推理框架，用 C++ 自研 Conv2D / Pooling / Dense 定点算子，配合对称 Int8 量化与双缓冲内存复用，单次推理 20–40 ms，峰值内存控制在 31 KB 以内。

1. 项目概述 (Overview)

ESP-Net 旨在验证轻量级神经网络在嵌入式端的实时推理能力。项目以经典的 MNIST 手写数字识别为任务目标，构建了从离线训练到端侧部署的全生命周期链路。

核心技术特性：

  • 全链路自研：涵盖模型构建、数据增强、定点量化及嵌入式驱动开发。
  • 轻量化推理引擎：基于 C++ 实现底层卷积（Conv2D）、池化（Pooling）及全连接（Dense）算子，规避了框架级封装带来的冗余。
  • 高性能定点化：采用对称量化（Symmetric Quantization）策略将参数压缩至 8-bit，显著降低了 Flash 占用与内存吞吐量。
  • 实时交互反馈：集成 LovyanGFX 图形库，提供直观的数字化绘图区与实时类别概率分布展示。

2. 技术架构 (Architecture)

2.1 神经网络拓扑

系统采用针对端侧优化的轻量级 CNN 架构，确保在保证分类精度的前提下，最大限度减少乘累加（MAC）运算量：
Input(28x28x1) -> Conv2D(8, 3x3) -> BN -> ReLU -> MaxPool -> Conv2D(16, 3x3) -> BN -> ReLU -> MaxPool -> Flatten -> Dense(64) -> Dense(10)

2.2 离线训练与压缩优化

  • 鲁棒性增强：在训练阶段引入旋转（±10°）、缩放及平移等数据增强手段，提升模型对异形字体的泛化能力。
  • 算子融合（Folded BN）：将 Batch Normalization 层参数预先融合进卷积层的权重（Weights）与偏置（Bias）中，实现推理阶段的零额外开销。

2.3 嵌入式端实现

推理核心模块 nn_ops.cpp 针对 ESP32 的存储特性进行了优化：

  • 内存复用：通过双缓冲（Double Buffer）机制管理激活值，将峰值内存控制在 31KB 以内。
  • 高效卷积：实现了支持 Same Padding 的定点卷积算法。

3. 实验结果与性能评估 (Benchmarks)

3.1 精度分析

模型在 MNIST 测试集上表现优异。通过混淆矩阵分析，系统对相似字符（如 4/9, 5/6）具备良好的辨析能力。

训练收敛曲线 混淆矩阵 错误样本聚类

3.2 硬件运行效率

  • 推理延迟：单次识别耗时控制在 20ms-40ms，满足实时交互需求。
  • 资源占用：Int8 量化后的模型参数仅占用数十 KB 存储空间。

5. 快速上手 (Quick Start)

  1. 环境配置：克隆仓库并安装 PyTorch 及 PlatformIO 开发环境。
  2. 训练与导出：运行 train_mcu.py 获取权重，通过 export_weights.py 生成 C 语言头文件。
  3. 固件编译：在 LVGL8-WT32-SC01-Arduino 工程中导入权重并上传至 ESP32。
