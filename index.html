ESP-Net：基于 ESP32 的轻量级嵌入式手写数字识别系统设计与实现

Posted on 2026-04-22 Edited on 2026-08-15 In 项目实战

摘要： 在资源受限的微控制器（MCU）上部署深度学习模型，通常面临算力开销与内存占用的双重挑战。ESP-Net 项目展示了一套完整的端侧 AI（TinyML）落地方案。该方案摒弃了笨重的第三方推理框架，通过自主实现 C++ 推理算子及 Int8 定点量化技术，在 ESP32 (WT32-SC01) 平台上实现了高精度的实时手写数字识别。

1. 项目概述 (Overview)

ESP-Net 旨在验证轻量级神经网络在嵌入式端的实时推理能力。项目以经典的 MNIST 手写数字识别为任务目标，构建了从离线训练到端侧部署的全生命周期链路。

核心技术特性：

  • 全链路自研：涵盖模型构建、数据增强、定点量化及嵌入式驱动开发。
  • 轻量化推理引擎：基于 C++ 实现底层卷积（Conv2D）、池化（Pooling）及全连接（Dense）算子，规避了框架级封装带来的冗余。
  • 高性能定点化：采用对称量化（Symmetric Quantization）策略将参数压缩至 8-bit，显著降低了 Flash 占用与内存吞吐量。
  • 实时交互反馈：集成 LovyanGFX 图形库，提供直观的数字化绘图区与实时类别概率分布展示。

2. 技术架构 (Architecture)

2.1 神经网络拓扑

系统采用针对端侧优化的轻量级 CNN 架构，确保在保证分类精度的前提下，最大限度减少乘累加（MAC）运算量：
Input(28x28x1) -> Conv2D(8, 3x3) -> BN -> ReLU -> MaxPool -> Conv2D(16, 3x3) -> BN -> ReLU -> MaxPool -> Flatten -> Dense(64) -> Dense(10)

2.2 离线训练与压缩优化

  • 鲁棒性增强：在训练阶段引入旋转（±10°）、缩放及平移等数据增强手段，提升模型对异形字体的泛化能力。
  • 算子融合（Folded BN）：将 Batch Normalization 层参数预先融合进卷积层的权重（Weights）与偏置（Bias）中，实现推理阶段的零额外开销。

2.3 嵌入式端实现

推理核心模块 nn_ops.cpp 针对 ESP32 的存储特性进行了优化：

  • 内存复用：通过双缓冲（Double Buffer）机制管理激活值，将峰值内存控制在 31KB 以内。
  • 高效卷积：实现了支持 Same Padding 的定点卷积算法。

3. 实验结果与性能评估 (Benchmarks)

3.1 精度分析

模型在 MNIST 测试集上表现优异。通过混淆矩阵分析，系统对相似字符（如 4/9, 5/6）具备良好的辨析能力。

3.2 硬件运行效率

  • 推理延迟：单次识别耗时控制在 20ms-40ms，满足实时交互需求。
  • 资源占用：Int8 量化后的模型参数仅占用数十 KB 存储空间。

  1. 环境配置：克隆仓库并安装 PyTorch 及 PlatformIO 开发环境。

GD-Net：面向 MCU 级边缘侧设备的资源高效型目标检测框架

Posted on 2026-04-22 In 项目实战

摘要： 在资源极度受限的嵌入式设备（如 MCU、IoT 终端）上实现高精度、实时的目标检测，始终是边缘智能领域的重大挑战。传统的轻量化 YOLO 模型往往因参数量和内存需求，难以适配 SRAM 仅为数百 KB 的硬件环境。本文提出 GD-Net (Generalized Detection Network)，通过集成硬件感知神经架构搜索（MCUNet/TinyNAS）获得的极致骨干网络，并结合解耦检测头 (Decoupled Head) 与 SPPF 技术，在仅 1.016M 参数和 651M FLOPs 的计算开销下，实现了在低功耗边缘侧的卓越检测性能。

1. 引言与动机 (Introduction & Motivation)

随着无人机自主导航、工业自动化巡检及智能家居生态的快速发展，在超低功耗微控制器（MCU）上部署复杂视觉算法的需求日益增长。然而，即便是目前最紧凑的标准模型（如 YOLOv5n，约 1.9M 参数），对于内存敏感型设备而言其静态存储与运行内存占用依然过高。

GD-Net 的设计目标在于打破算法复杂度与硬件限制之间的壁垒，专注于在 <5MB 磁盘占用与 <1MB SRAM 占用的极端约束下，提供具备商业应用价值的检测能力。

核心技术贡献：

  • 硬件感知的 NAS 骨干网络： 采用 TinyNAS 搜索出的 MCUNet 主干，针对特定硬件算子延迟进行深度优化。
  • 解耦检测头 (Decoupled Head)： 通过分离分类与定位任务，在提升约 2%-3% mAP 的同时，有效加速了模型的收敛过程。
  • 高效特征聚合机制： 引入改进型 PANet 结构并辅以 SPPF (Spatial Pyramid Pooling - Fast)，在不显著增加计算负担的前提下大幅提升了感受野。
  • 全链路 TFLite 部署支持： 原生适配 Int8 量化流程，使模型压缩至 1.2MB 级别，确保在端侧设备上的部署一致性。

2. 核心架构设计 (Architectural Methodology)

GD-Net 秉持“模块化与高能效”的设计哲学，通过优化 Backbone 与 Head 之间的参数分配权重，最大化特征提取单元的利用率。

2.1 骨干网络：MCUNet 的硬件适配优势

GD-Net 摒弃了传统的 Darknet 结构，转而采用由 ProxylessNAS 搜索出的轻量级算子组合。针对不同算力梯度的 MCU 平台，GD-Net 提供了灵活的可扩展配置：

  • GD-Net-S (Small)：基于 mcunet-256kb-1mb 搜索空间，适配 512KB SRAM 等级的设备。
  • GD-Net-M (Medium)：在检测精度与推理延迟之间实现最优权衡。
  • GD-Net-L (Large)：针对高性能边缘计算单元（如 Jetson Nano、ESP32-S3）设计的增强版本。

2.2 模块化配置体系 (cfg.py)

在 320x320 的标准输入分辨率下，我们将 GD-Net 与当前主流的轻量化目标检测模型在 Pascal VOC 数据集上进行了对比实验：

4. 部署工作流：从训练到终端推理

GD-Net 的核心优势之一在于其简洁的部署链路，大幅降低了从 PyTorch 训练环境到 MCU 二进制文件的迁移成本。

5. 结论与展望

GD-Net 的研究实践证明，通过将硬件感知神经架构搜索（NAS）与先进的检测器设计（如 YOLOv3-PAN 与解耦头）相结合，可以在微瓦级的算力预算下实现高性能的视觉感知能力。

未来研究方向：

  1. 结构重参数化：探索集成 RepVGG 式算子，以在不增加推理成本的前提下进一步提升特征表达能力。
  2. Anchor-free 架构演进：研究向 YOLOv8 风格的无锚点检测头过渡，简化后处理流程。
  3. 硬件特定优化：针对专用嵌入式 NPU 加速器优化算子融合策略。

Drone-10k：一个包含1万张高清目标的无人机检测数据集

Posted on 2025-12-15 In 技术分享

摘要： 分享一个自制的无人机检测数据集 Drone-10k。数据量大约 10,000 张，融合了西湖大学公开数据与个人采集数据，主要包含三类无人机机型 DJI Mini、DJI Air和大疆精灵。核心亮点是目标尺寸均 >16x16 像素，剔除了极小噪点。如果有需要的同学可以下载使用，希望对大家有用。

1. 为什么做这个数据集？

起初，这其实是我的硕士毕业设计课题——《小目标无人机检测与拦截控制研究》的一部分。在完成这个课题的过程中，我发现了一个很尴尬的现实：

  1. 现实与数据的割裂： 现实生活中，我们要防范或拦截的绝大多数都是大疆（DJI） 这种消费级无人机。
  2. 开源数据的匮乏： 但翻遍了市面上的公开数据集，很多都是大型客机和零散的不知名的无人机，真正包含高清大疆无人机的数据少之又少。

为了解决这个问题，让模型真正具备实战能力，我和我的学弟学妹们，一点点采集、清洗、融合了这份数据，这里也特别感谢他们的帮助。

关于数据的清洗与重采样

必须说明的是，我们原始采集的数据量其实高达 50,000 张。但在分析阶段我们发现，自采数据虽然清晰，但受限于大疆无人机设备，存在无人机型号和类别单一的问题。

为了保证数据集的泛化性和平衡性，我们没有简单地堆砌数量，而是采取了一定的筛选策略：

  1. 去噪： 对自建库和西湖大学开源数据执行同样的预处理，剔除所有小于 16*16 像素的无效噪点。
  2. 重采样： 从自建库和西湖大学筛选后的数据库中，随机下采样（Under-sampling） 了 10,000 张 最具代表性的样本。

最终，我们得到了这份去粗取精、总量约 1万张 的 Drone-10k 数据集。

核心特性：

  • 📸 数据量大： 包含 10,000+ 张真实场景图片。
  • 🔍 拒绝模糊： 严格筛选标准，所有标注目标的尺寸均在 16×16 像素以上（有效特征区域）。
  • 🌍 场景丰富： 涵盖天空、城市、野外、逆光等多种复杂环境。


图1：Drone-10k 数据集概览（1000张样本的密集阵列展示）。每一个方格都是一个清晰的无人机目标，而非模糊的黑点。

2. 数据可视化分析

为了证明数据的质量，我们对 1w 张标注数据进行了深度的统计分析。

2.1 目标尺寸分布：清晰可见的细节

很多检测模型（如 YOLO 系列）对微小目标（<16px）极其敏感且难训练。我们将所有目标的宽(Width)和高(Height)绘制了密度散点图：


图2：目标尺寸分布图（密度着色）。

  • 分析： 从图中可以看出，数据集中绝大多数样本都落在中等尺寸区间。虽然存在长宽比的变化，但几乎没有极小尺寸的噪点样本。这保证了卷积神经网络（CNN）能够提取到有效的纹理特征，而不仅仅是学习背景噪声。

2.2 空间分布：拒绝“中心过拟合”

为了验证拍摄时是否存在严重的偏差，我们绘制了所有目标在画面中的位置热力图：


图3：目标位置热力图。

  • 分析：
    • 中心热点： 黄色区域显示存在一定的摄影师中心跟随习惯，符合真实应用场景。
    • 边缘覆盖： 紫色区域广泛覆盖了画面的四周角落。这意味着数据集包含大量无人机飞出视野中心、位于边缘的困难样本。
    • 结论： 使用本数据集训练的模型，将具有更好的鲁棒性，不会养成“只看画面中间”的坏习惯。
